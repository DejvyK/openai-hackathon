## Current-evidence post

What changes when the page becomes the starting point for an agent?

For the Agents, Everywhere hackathon, I’m building AgentLayer: a browser extension that keeps research and the next action tied to the content you are reading.

A profile provides context for a reviewed contact and follow-up. A selected passage provides context for a research note. OpenAI and Exa have produced sourced research in recorded backend runs; the complete browser-to-Ambiguous save journeys still need verification.

I built this prototype solo, with Codex helping with implementation, testing and documentation. The local two-minute evidence review shows actual research reports and clearly labels the remaining gaps. It is an evidence walkthrough, not a recording of a completed live workflow.
